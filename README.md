# notes

- `npx quartz build --serve`
- (Prefer `git` but) `npx quartz sync`

Uses [quartz](https://quartz.jzhao.xyz/) to get the most out of Obsidian (`draft.ts` is changed to `share: true` rather than `draft: false` to match with [Obsidian GitHub Publisher](https://github.com/ObsidianPublisher/obsidian-github-publisher), which populates the `content/` folder with a fixed folder path.). Followed the [quartz documentation](https://quartz.jzhao.xyz/) and Nicole van der Hoeven's [video](https://www.youtube.com/watch?v=6s6DT1yN4dw).

Deployed at [theorashid.github.io/notes](https://theorashid.github.io/notes).
